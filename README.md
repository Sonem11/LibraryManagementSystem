# Library Management System

## Project Overview
This project demonstrates object-oriented programming (OOP) in Python through a simple library management system.  
We define classes for `Book`, `Member`, and `Library` to manage borrowing and returning books.

## Technologies Used
- Python 3.14

## Scripts
- `book.py` → Defines the `Book` class with borrow/return methods.  
- `member.py` → Defines the `Member` class with borrowed books tracking.  
- `library.py` → Defines the `Library` class to manage collections of books and members.  
- `main.py` → Demonstrates adding books, members, borrowing, and returning.  

## Results
- Books can be borrowed and returned.  
- Members are tracked with their borrowed books.  
- Library lists available and borrowed books.
